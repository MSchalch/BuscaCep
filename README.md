# 🔎 Busca CEP Web

Projeto de busca de CEP que utiliza uma API pública (ViaCEP) para retornar informações de endereço a partir de um CEP informado. A aplicação possui:

- ✅ Backend em Java com Spring Boot
- 🎨 Frontend em HTML e CSS com layout responsivo
- 🌐 Consumo de API via `fetch()`
- ☁️ Pronto para deploy com Vercel (frontend) e Render (backend)

---

## 📦 Tecnologias utilizadas

- Java 17+
- Spring Boot
- HTML5 + CSS3
- JavaScript (Vanilla)
- API pública: [https://viacep.com.br](https://viacep.com.br)

---

## 🧠 Como funciona

1. O usuário acessa a página web e digita um CEP.
2. O frontend faz uma requisição `GET` para o backend Java.
3. O backend consulta a API do ViaCEP e retorna os dados do endereço.
4. O frontend exibe as informações formatadas na tela.
